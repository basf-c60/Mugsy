Mugsy: annotated disassembly

The VM

The interpreter (30092) keeps its program counter at 30090 and its accumulator in BCDE, with a second operand in BC'DE' (called alt in the table below). "v" operands are one-byte variable numbers; "addr" operands are two-byte addresses. Comparisons jump to the address when the condition holds. The flags returned by each instruction survive into the next, so JZ after CALL tests the result of the native routine.
Op Mnemonic Operands Action
0 END | Return from the interpreter
1 SAY addr, flags, [extra] Show the message at addr in a speech bubble (28549). Any number or money placeholders in the message take one variable number each from the bytes that follow; sub-message placeholders take an address.
2 SETMSG addr Set the default sub-message (used by a sub-message placeholder whose address is 0)
3 IFEQ v1, v2, addr Jump if v1 = v2
4 IFNE v1, v2, addr Jump if v1 <> v2
5 IFLE v1, v2, addr Jump if v1 <= v2
6 IFLT v1, v2, addr Jump if v1 < v2
7 IFGT v1, v2, addr Jump if v1 > v2
8 IFGE v1, v2, addr Jump if v1 >= v2
9 IFPEEKEQ addr1, n, addr2 Jump to addr2 if PEEK addr1 = n
10 IFPEEKNE addr1, n, addr2 Jump to addr2 if PEEK addr1 <> n
11 POKE n, addr POKE addr, n
12 JZ addr Jump if the zero flag is set
13 GOTO addr Jump
14 CALL addr Call a Z80 routine
15 STORE v v = acc
16 / 17 / 18 ADD - / v / v1,v2 acc = acc+alt / acc+v / v1+v2
19 / 20 / 21 SUB - / v / v1,v2 acc = acc-alt / acc-v / v1-v2
22 / 23 / 24 MUL - / v / v1,v2 acc = acc*alt / acc*v / v1*v2 (fixed point)
25 / 26 DIV v / v1,v2 acc = acc/v / v1/v2 (0 if dividing by 0)
27 INT | acc = whole part of acc
28 LOAD v acc = v
29 / 30 RND - / v acc = a random number from 0 to acc (or v), worked out on the low byte only, so RND v71 (v71 = 1.00) gives 0.00 to 1.00 (see the trivia entry on random numbers)
31 NEG | acc = -acc
32 HALF v acc = v/2
33 / 34 SQRT - / v acc = square root of acc (or v)
