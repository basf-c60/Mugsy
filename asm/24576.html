24576: Start the game
This is the entry point (from PRINT USR 24576 in the BASIC loader). It disables interrupts, moves the stack down into the printer buffer, saves IY (which the ROM interrupt routine needs) and calls the main loop. When the player answers "nope" to "Hows about another game, Mugsy?" the main loop returns here and the machine locks up in an infinite loop (see the bugs page).
24576 DI Disable interrupts
24577 LD SP,23552 Put the stack in the printer buffer, just below the system variables
24580 LD (33900),IY Save IY (the ROM interrupt routine needs it to point at the system variables)
24584 CALL 24589 Play games until the player has had enough
24587 JR 24587 Then hang forever (see the bugs page)
