26812: Draw the picture for a speech bubble layout
IY points at a 4-byte bubble layout entry: byte 0 is the bubble placement chance, bytes 1-2 are the address of the picture data and byte 3 is the border colour. If the same layout is still on screen (33906=0) the screen is left alone except that the speech bubbles are wiped (cells with attribute 120 cleared); otherwise the screen is cleared and the picture is redrawn by 31247.
Input
IY Layout entry
26812 LD A,(IY+3) Set the border colour for this layout
26815 OUT (254),A Set the border to the layout's colour
26817 PUSH HL Keep the caller's HL
26818 LD L,(IY+1) Pick up the address of the layout's picture
26821 LD H,(IY+2) H=high byte of the picture address (HL=picture address)
26824 EX (SP),HL HL=the caller's HL again; the picture address is on the stack
26825 POP IY IY=picture data
26827 LD A,(33906) Has the layout changed?
26830 AND A Test the layout-changed flag
26831 JP NZ,31247 If so, draw the whole picture
26834 PUSH HL Otherwise just wipe the speech bubbles: they are the cells with attribute 120
26835 PUSH DE Save DE...
26836 PUSH BC ...and BC
26837 LD HL,16384 HL=display file
26840 LD DE,22528 DE=attribute file
26843 LD A,D Reached the end of the attribute file?
26844 CP 91 Is this the end of the attribute file (high byte 91)?
26846 JR Z,26872 Finish if so
26848 LD A,(DE) Is this cell part of a bubble (bright white)?
26849 CP 120 Is the cell bright white paper (a bubble cell)?
26851 JR NZ,26862 Jump if not
26853 PUSH HL Keep the cell's address
26854 LD B,8 Clear the 8 pixel rows of the cell
26856 LD (HL),0 Clear one pixel row of the cell
26858 INC H Down to the next pixel row
26859 DJNZ 26856 Repeat for all eight pixel rows
26861 POP HL Back to the top of the cell
26862 INC DE Next attribute
26863 INC L Next cell
26864 JR NZ,26843 Jump back unless a third of the screen is done
26866 LD A,H A=H: the current screen third...
26867 ADD A,8 Move to the next third
26869 LD H,A H=the next third
26870 JR 26843 Carry on with the next cell
26872 POP BC Restore BC...
26873 POP DE ...DE...
26874 POP HL ...and HL
26875 RET Done: all speech bubbles are wiped
