26876: Wait for a key to be pressed or for a timeout
First waits until all keys are released, then waits (up to A periods of about one second each) for a key to be pressed. Used after each speech bubble.
Input
A Number of timeout periods
26876 PUSH AF Save AF...
26877 PUSH BC ...and BC
26878 LD B,A B=number of timeout periods
26879 XOR A Select every keyboard half-row (high byte of the port = 0)
26880 IN A,(254) Read every half-row of the keyboard
26882 AND 31 Keep the key bits only
26884 CP 31 Are all keys released?
26886 JR NZ,26879 Wait until they are
26888 CALL 26898 Wait about a second for a keypress
26891 JR NZ,26895 Finish if a key was pressed
26893 DJNZ 26888 Otherwise try again for up to B periods
26895 POP BC Restore BC...
26896 POP AF ...and AF
26897 RET Done: Z set if the time ran out, NZ if a key was pressed
