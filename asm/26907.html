26907: Wait for a keypress for up to BC iterations
Returns with the zero flag reset as soon as a key is pressed, or with the zero flag set after BC loops.
Input
BC Loop count
26907 XOR A A=0: select every keyboard half-row
26908 IN A,(254) Read every half-row of the keyboard
26910 AND 31 Keep the key bits
26912 CP 31 Is any key pressed?
26914 RET NZ Return (zero flag reset) if so
26915 DEC BC Count down
26916 LD A,B Is BC zero? Test B...
26917 OR C ...together with C
26918 JR NZ,26907 Keep waiting until BC is zero
26920 RET Return with the zero flag set (timeout)
