26940: Print a character in the proportional font
Prints character A at pixel offset C within the cell at HL. The glyph is six pixels high and starts one pixel row down. Characters may straddle two cells, so each row is shifted into place by 27021, which also clears the pixels behind the glyph. The dollar sign and the comma get a seventh row (a tail below the line). On exit C and L have been moved past the character plus one pixel of spacing.
Input
A Character code
C Pixel offset (0-7) within the current cell
HL Display file address
Output
C Updated pixel offset
L Updated column
