27021: Print one pixel row of a glyph
Shifts the pixel row in A right by C bits across a 16-bit word and ORs it into the two screen bytes at HL and HL+1, using the mask at 27018.
Input
A Pixel row
C Pixel offset
HL Display file address
27021 PUSH DE Save DE
27022 LD D,A D=pixel row
27023 LD E,0 E=0 (the overflow into the next cell)
27025 PUSH BC Save BC
27026 LD A,C A=pixel offset
27027 LD BC,(27018) BC=glyph mask
27031 AND A Is the offset 0?
27032 JR Z,27046 Jump if so
27034 SRL D Shift the row right one pixel...
27036 RR E The bits that fall off go into E
27038 SCF ...and the mask, bringing in a 1
27039 RR B Shift a 1 into the mask (B)...
27041 RR C ...and on into C
27043 DEC A One fewer shift to go
27044 JR NZ,27034 Repeat for each pixel of the offset
27046 LD A,B Clear the pixels behind the glyph in the first cell...
27047 AND (HL) Keep the background pixels outside the glyph
27048 OR D ...and draw the left part of the row
27049 LD (HL),A Store the combined byte
27050 INC L Next cell
27051 LD A,C Do the same for the second cell
27052 AND (HL) Keep the background pixels in the second cell
27053 OR E Add the overflow from the shifted row
27054 LD (HL),A Store it
27055 DEC L Back to the first cell
27056 POP BC Restore BC
27057 POP DE Restore DE
27058 RET Done
