27060: Clear a character cell and set its attribute
Clears the eight bytes of the character cell at HL and sets its attribute to the value at 27059.
Input
HL Display file address
27060 PUSH HL Save the cell address
27061 PUSH AF Keep the attribute value
27062 LD A,8 8 pixel rows
27064 LD (HL),0 Clear one
27066 INC H Next pixel row
27067 DEC A One fewer row to clear
27068 JR NZ,27064 Repeat for all eight rows
27070 LD A,H Work out the attribute address from the display file address
27071 DEC A H-1: the display file third is now 0-2 in bits 3-4
27072 RRCA Move the third number...
27073 RRCA ...down into the low bits...
27074 RRCA ...(three rotates)
27075 AND 3 Keep the two bits of the third
27077 ADD A,88 Add the high byte of the attribute file
27079 LD H,A H=attribute address high byte
27080 LD A,(27059) Set the attribute
27083 LD (HL),A Set the cell's attribute
27084 POP AF Restore the attribute value
27085 POP HL Restore the screen address
27086 RET Done: the cell is blank with the new attribute
