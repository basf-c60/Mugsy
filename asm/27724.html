27724: Print a character using the ROM font
Used for the status line at the bottom of the screen. Copies the 8x8 glyph from the ROM character set (15360+8*A) to the cell at HL, then moves HL one cell right.
Input
A Character code
HL Display file address
27724 PUSH DE Save DE (the screen address)
27725 PUSH BC Save BC...
27726 PUSH HL ...and HL
27727 LD L,A HL=character code
27728 LD H,0 HL=character code
27730 ADD HL,HL HL=2*code
27731 ADD HL,HL HL=4*code
27732 ADD HL,HL HL=8*code
27733 LD DE,15360 Add 15360 (the ROM character set minus 256)
27736 ADD HL,DE HL=address of the glyph in the ROM font
27737 POP DE DE=screen address
27738 PUSH DE Keep the screen address
27739 EX DE,HL HL=screen, DE=glyph
27740 LD B,8 8 pixel rows
27742 LD A,(DE) Copy a row
27743 LD (HL),A Store the glyph row on the screen
27744 INC DE Next glyph row
27745 INC H Next pixel row
27746 DJNZ 27742 Repeat for all 8 rows
27748 POP HL HL=screen address
27749 POP BC Restore BC
27750 POP DE Restore DE
27751 INC L Move one cell right
27752 RET Done: the character is on screen and HL has moved right
