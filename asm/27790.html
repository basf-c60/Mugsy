27790: VM native: get a number from the player
Reads a line of input and parses it into v35 (in hundredths, like all VM numbers). On an invalid entry Louey complains (script at 27807 or 27828 for fractions) and the blunder count v11 goes up. Flag 8 (33896) is set to the type of the answer: 1 = negative, 2 = zero, 3 = 0.01 (not possible from the keyboard), 4 = anything else.
27790 CALL 28037 Read a line of input
27793 CALL 27869 Parse it as a number into v35
27796 JR NZ,27817 Jump unless it was invalid
27798 LD IY,27807 Louey says "What wuz dat, Boss?..." (and the blunder count goes up)
27802 CALL 30092 Run the script that asks what he said
27805 JR 27790 Ask again
