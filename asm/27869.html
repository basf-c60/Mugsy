27869: Parse the input buffer as a number
Checks the text at 23808 for an optional sign, digits and a decimal point, then runs the small VM scripts at 27995, 28000 and 28006 to accumulate the value in v35 (each digit: v35=v35*10+digit*100). Returns with the zero flag reset if the entry was not a valid whole number, and with the carry flag reset if it contained a decimal point.
