28021: Check whether A is a digit
Returns with the carry flag set if A is "0"-"9".
Input
A Character code
Output
F Carry set if A is a digit
28021 CP 48 Below "0"?
28023 JR C,28028 Jump if so
28025 CP 58 Below ":" (i.e. "0"-"9")?
28027 RET C Return with the carry flag set if so
28028 XOR A Set the zero flag (and reset the carry flag): not a digit
28029 RET Done: Z means not a digit
