28266: Wait one frame and read the keyboard
Enables interrupts long enough for one ROM interrupt (which scans the keyboard), then checks bit 5 of FLAGS to see if a new key has been pressed.
Output
A Key code (if the zero flag is reset)
28266 PUSH IY Save IY
28268 PUSH HL Save HL
28269 PUSH BC Save BC
28270 LD IY,(33900) Restore IY for the ROM interrupt routine
28274 EI Let one interrupt happen (the ROM scans the keyboard)
28275 HALT Wait for the next interrupt
28276 DI Interrupts off again
28277 LD A,(23611) Has a new key been pressed?
28280 BIT 5,A Is the ROM's new-key flag (bit 5 of FLAGS) set?
28282 JR Z,28292 Jump if not

28289 LD A,(23560) A=the key code
