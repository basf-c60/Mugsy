28530: Print a VM variable into a status line template
Formats variable D into the template at HL (A characters long) via 29630.
Input
A Field width
D Variable number
HL Template address
28530 PUSH HL Save the template address
28531 LD L,D L=the variable number
28532 CALL 31201 BCDE=its value
28535 POP HL HL=the template address
28536 LD (29926),HL Remember where the number goes
28539 LD (HL),32 Blank the field with spaces
28541 INC HL Next character of the field
28542 DEC A One fewer
28543 JR NZ,28539 Loop until the field is blank
28545 JP 29630 Print the value into the field
