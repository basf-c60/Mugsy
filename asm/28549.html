28549: Show a message in a speech bubble
The handler for VM op 1 (SAY, 30225) jumps here. This is the heart of the comic strip display. HL holds the address of a message and A holds a flags byte:
Bits Meaning
0-1 Non-zero: wait for a keypress (with timeout) afterwards
2-3 Bubble placement: 0 = random entry from the layout table at 33902; 4 (bit 2) = the fixed entry at 33909 (the answer bubble); 8 (bit 3) = keep the current entry
4-6 16 = play the theme tune (32785)
Input
The message is rendered into the text buffer at 23808 (expanding dictionary words and any variables, which are taken from the VM byte stream after the SAY instruction), the picture is redrawn if the layout has changed, the status lines are printed and the text is word-wrapped into the bubble by 28757.
