28671: Measure the words in the text buffer
Builds a list of word widths (in pixels) at 24192, terminated by 255.
Input
IX Text
28671 LD DE,24192 Point DE at the word width list
28674 PUSH IX Save IX...
28676 PUSH HL ...and HL
28677 CALL 28698 Measure the next word
28680 AND A Was it empty (two spaces in a row)?
28681 JR Z,28685 Skip it if so
28683 LD (DE),A Store its width
28684 INC DE Next entry in the table
28685 LD A,(IX+0) Reached the end of the text?
28688 AND A Clear the carry flag
28689 JR NZ,28677 Back for the next word if not
28691 LD A,255 Terminate the list with 255
28693 LD (DE),A Store the measured value
28694 POP HL Restore HL
28695 POP IX Restore IX
28697 RET Done
