28698: Measure one word
Adds up the widths (+1 pixel spacing) of the characters at IX up to the next space.
Input
IX Text
Output
A Width in pixels
IX Next word
28698 PUSH BC Save BC
28699 PUSH HL Save HL
28700 LD C,0 C will accumulate the width
28702 LD A,(IX+0) Pick up a character
28705 AND A End of the text?
28706 JR Z,28724 Finish if so
28708 CALL 26921 Get the address of its glyph
28711 LD A,(HL) A=width of the character
28712 INC A +1 pixel of spacing
28713 ADD A,C Add the character's width to the total
28714 LD C,A Add it to the total
28715 LD A,(IX+0) Pick up the character again
28718 INC IX Move on
28720 CP 32 Was it a space?
28722 JR NZ,28702 Carry on until the end of the word
28724 POP HL Restore HL
28725 LD A,C A=width of the word
28726 POP BC Restore BC
28727 RET Done: A=the width of the word in pixels
