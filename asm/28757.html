28757: Print the text buffer into a speech bubble
Works out how many lines the text needs (29161), then prints it line by line, centring each line within the oval bubble shape described by the table of line widths at 28728 and left margins at 28746. The bubble outline itself is drawn first by 28905.
Input
IX Text
HL Display file address of the top of the bubble
