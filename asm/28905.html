28905: Draw the outline of a speech bubble
Draws the rounded white bubble (paper 7) with one blank line above and below the text area.
28905 PUSH IY Save IY
28907 PUSH HL Save the registers this routine uses...
28908 PUSH DE ...(HL=screen position, DE=width table)...
28909 PUSH BC ...and BC, which will count rows
28910 CALL 28895 Start one row above the text
28913 LD A,(28755) B=number of lines in the top half
28916 LD B,A B=lines in the top half...
28917 LD A,(28756) ...plus the lines in the bottom half (28756)...
28920 ADD A,B ...to give the number of rows above the middle line
28921 LD B,A B=the row counter
28922 LD C,0 C=pixel offset 0
28924 PUSH HL Keep the screen position for the next row
28925 CALL 28879 Indent by the margin
28928 LD A,(DE) A=width of this line
28929 CALL 29006 Paint the white background for it
28932 POP HL Back to the start of this row
28933 INC IY Next margin entry
28935 INC DE Next line width
28936 CALL 28885 Move down a row
28939 DJNZ 28922 Repeat for the top half
28941 PUSH HL Keep the screen position of the middle row
28942 DEC DE Back to the widest line
28943 DEC IY Back to the widest line's margin entry
28945 CALL 28879 Indent by the margin
28948 LD A,(DE) A=the width of the widest line
28949 CALL 29006 Paint the blank row above the text (as wide as the line below it)
28952 LD A,(28755) Is there an odd middle line?
28955 AND A Test for no odd middle line
28956 JR Z,28961 Skip the extra step if there is none
28958 DEC DE Odd middle line: step back one more width...
28959 DEC IY ...and one more margin entry
28961 POP HL Restore the screen position
28962 CALL 28885 Move down a row
28965 PUSH HL Keep the screen position of the middle row
28966 CALL 28879 Indent by the margin of the middle line
28969 LD A,(DE) A=width of the middle line
28970 CALL 29006 Paint the middle row
28973 POP HL Restore the screen position
28974 LD A,(28756) B=number of lines in the bottom half
28977 LD B,A B=lines in the bottom half
28978 AND A Test for none
28979 JR Z,29000 Jump if there are none
28981 LD C,0 C=pixel offset 0
28983 CALL 28885 Move down a row
28986 PUSH HL Keep the screen position
28987 CALL 28879 Indent by the margin
28990 LD A,(DE) A=the width of the line
28991 CALL 29006 Paint the background for this line
28994 POP HL Restore the screen position
28995 DEC IY Previous margin
28997 DEC DE Previous width
28998 DJNZ 28981 Repeat for the bottom half
29000 POP BC Restore BC...
29001 POP DE ...DE...
29002 POP HL ...HL...
29003 POP IY ...and IY
29005 RET Done: the whole bubble background is painted
