29029: Print one line of text in a bubble
Prints as many words from IX as will fit in A pixels, centred.
Input
A Line width in pixels
IX Text
29029 PUSH BC Save BC
29030 PUSH DE Save DE
29031 LD B,A B=the width of the line in pixels
29032 LD A,(IX+0) A=the first character of the text
29035 AND A Test it
29036 JR Z,29157 End of the text: nothing to print
29038 PUSH IX Save the start of the line
29040 LD (29027),IX Remember the start of the line
29044 LD A,(IX+0) A=the next character
29047 AND A Test it
29048 JR Z,29061 End of the text: the line ends here
29050 CALL 28698 Measure the next word
29053 LD D,A D=the width of the word
29054 LD A,B A=the width left on the line
29055 SUB D Subtract the word's width
29056 JR C,29061 It does not fit: the line ends before this word
29058 LD B,A B=the width left
29059 JR 29040 Try the next word
29061 POP DE DE=the start of the line
29062 PUSH BC Save the width left
29063 PUSH DE Save the start of the line
29064 PUSH HL Save the screen position
29065 LD HL,(29027) HL=the end of the words that fit (where the next word starts)
29068 AND A Clear the carry flag
29069 SBC HL,DE Subtract the start: the number of characters on the line
29071 LD A,L A=the character count
29072 POP HL Restore the screen position
29073 LD C,A C=the character count
29074 LD E,250 E=250: a counter for the spaces at the end of the line
29076 LD D,254 D=254: a counter for the spaces at the start of the line
29078 LD IX,(29027) IX=the end of the line
29082 LD B,C B=the character count
29083 DEC IX Back up one character
29085 INC D Count it in D
29086 INC E Count three pixels in E for each space...
29087 INC E ...
29088 INC E ...
29089 LD A,(IX+0) A=the character
29092 CP 32 A space?
29094 JR NZ,29098 No: stop looking
29096 DJNZ 29083 Keep looking for spaces at the end
29098 POP IX IX=the start of the line
29100 DEC IX Step back one
29102 LD B,C B=the character count
29103 INC E Count three pixels in E for each space at the start...
29104 INC E ...
29105 INC E ...
29106 INC D Count it in D
29107 INC IX Move on one character
29109 LD A,(IX+0) A=the character
29112 CP 32 A space?
29114 JR NZ,29118 No: stop looking
29116 DJNZ 29103 Keep looking for spaces at the start
29118 LD A,E A=the pixels to be trimmed
29119 LD E,C E=the character count
29120 POP BC Restore the width left
29121 ADD A,B Add it
29122 SRL A Halve it: this is the pixel offset that centres the line
29124 ADD A,C Add the character count
29125 CP 8 At least 8 pixels?
29127 JR C,29134 No: that is the pixel offset within the cell
29129 SUB 8 Take off a character cell's 8 pixels
29131 INC L Move one cell right
29132 JR 29125 Repeat
29134 LD C,A C=the pixel offset within the first cell
29135 LD A,E A=the character count
29136 SUB D Take off the spaces to be skipped
29137 LD E,A E=the number of characters to print
29138 JR C,29153 None: nothing to print
29140 JR Z,29153 None: nothing to print
29142 LD A,(IX+0) A=the character
29145 CALL 26940 Print it in the proportional font
29148 INC IX Next character
29150 DEC E One fewer to print
29151 JR NZ,29142 Loop until the line is printed
29153 LD IX,(29027) IX=the end of the line (the start of the next one)
29157 POP DE Restore DE
29158 POP AF Restore AF
29159 LD B,A B=A
29160 RET Return
