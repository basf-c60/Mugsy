29161: Work out the bubble shape for the text
Chooses the smallest bubble (number of lines, B) into which the measured words will fit, using the line widths at 28728.
Output
B Number of lines

29163 PUSH IY Save IY
29165 LD IX,24191 IX=just before the list of word widths (24192)
29169 LD IY,24192 IY=the list of word widths
29173 LD A,(IY+0) A=a width
29176 INC IY Next one
29178 INC A The end marker is 255
29179 JR NZ,29173 Keep looking for it

29220 JR NC,29211 Yes: try another

29226 CALL 29236 Have the front and back met?
29229 JR C,29188 No: fill another line from the front
29231 POP IY Restore IY
