29458: Render one message item
A message is a sequence of items:
Byte(s) Meaning
0-31 Control code (see the table at 29248)
32-95 Literal character (letters are converted to lower case)
96-127 Common word: index into the table at 49710
128-255, n Dictionary word at 48640+((b AND 15)*256)+n; bits 4-6 of b: 7 = capitalise, 2 or 6 = last word, 3 = last word plus a full stop
Input
Returns with the zero flag set at the end of the message.
Input:IX Item Output:IX Next item
29458 LD A,(IX+0) Pick up the first byte of the item
29461 BIT 7,A Is it a two-byte dictionary reference?
29463 JR Z,29495 Jump if not
29465 AND 127 D=first byte without bit 7 (bits 0-3: page; bits 4-6: type)
29467 LD D,A D=the type and page
29468 LD E,(IX+1) E=offset into the page
29471 INC IX Point IX at the second byte
29473 AND 240 Keep the type bits
29475 CP 48 Type 3 (last word plus full stop)?
29477 JR Z,29578 Jump if so
29479 CP 32 Type 2 (last word)?
29481 JR Z,29578 Jump if so
29483 CP 96 Type 6 (last word)?
29485 JR Z,29578 Jump if so
29487 CALL 29928 Print the dictionary word
29490 INC IX Move IX to the next item
29492 OR 1 Reset the zero flag: the message continues
29494 RET Done: NZ means the message goes on
29495 CP 32 Is it a control code (0-31)?
29497 JR C,29544 Jump if so
29499 CP 96 Is it a common word (96-127)?
29501 JP NC,29907 Jump if so
29504 CALL 29509 Otherwise it is a literal character: put it in the buffer
29507 JR 29490 And move on
