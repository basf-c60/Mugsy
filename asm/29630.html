29630: Print a number
Prints the signed fixed-point value in BCDE in decimal (without leading zeros), adding a decimal point and two decimal places only if the fractional part is non-zero.
Input
BCDE Number (x100)
29630 BIT 7,B Is the number negative?
29632 JR Z,29642 Jump if not
29634 CALL 30634 Make it positive
29637 LD A,45 A="-"
29639 CALL 29509 Put the minus sign in the buffer
29642 PUSH BC Copy the high word (BC) into HL'
29643 EXX Switch to the alternate registers...
29644 POP HL ...HL'=high word of the number...
29645 EXX ...and back again
29646 EX DE,HL HL=low word
29647 XOR A Leading zeros are not printed yet
29648 LD (29629),A Clear the leading-zero flag
29651 LD BC,15258 BC/DE=1,000,000,000 (the number is in hundredths, so this is ten million)
29654 LD DE,51712 DE=low word of the divisor 1,000,000,000
29657 CALL 29752 Print that digit
29660 LD BC,1525 BC/DE=100,000,000
29663 LD DE,57600 DE=low word of 100,000,000
29666 CALL 29752 Print the millions digit
29669 LD BC,152 BC/DE=10,000,000
29672 LD DE,38528 DE=low word of 10,000,000
29675 CALL 29752 Print the hundred-thousands digit
29678 LD BC,15 BC/DE=1,000,000
29681 LD DE,16960 DE=low word of 1,000,000
29684 CALL 29752 Print the ten-thousands digit
29687 LD BC,1 BC/DE=100,000
29690 LD DE,34464 DE=low word of 100,000
29693 CALL 29752 Print the thousands digit
29696 LD BC,0 BC/DE=10,000
29699 LD DE,10000 DE=10,000
29702 CALL 29752 Print the hundreds digit
29705 LD BC,0 BC/DE=1,000 (tens)
29708 LD DE,1000 DE=1,000
29711 CALL 29752 Print the tens digit
29714 LD A,1 From now on zeros are printed (so 0 comes out as "0")
29716 LD (29629),A Set the leading-zero flag
29719 LD BC,0 BC/DE=100 (units)
29722 LD DE,100 DE=100
29725 CALL 29752 Print the units digit
29728 LD A,L Is there a fractional part?
29729 OR H Combine with H to test the fraction
29730 RET Z Return if not: whole numbers have no decimal point
29731 LD A,46 A="."
29733 CALL 29509 Put the decimal point in the buffer
29736 LD BC,0 BC/DE=10 (tenths)
29739 LD DE,10 DE=10
29742 CALL 29752 Print the tenths digit
29745 LD A,L A=hundredths digit
29746 ADD A,48 Convert it to ASCII
29748 CALL 29509 Put it in the buffer
29751 RET Done
