29790: Control code 11: repeat earlier text
The next byte is an offset back (n-256) to some text earlier in the message area, which is rendered up to its own end marker. This saves space where messages share phrases.
29790 PUSH IX Save the message pointer
29792 LD E,(IX+1) E=offset (as a negative number: the text is earlier in memory)
29795 LD D,255 D=255, so DE is a negative offset
29797 ADD IX,DE IX=address of the earlier text
29799 CALL 29452 Render it until its own end marker
29802 POP IX Restore the message pointer
29804 INC IX Skip the offset byte
29806 XOR A Set the zero flag: code done
29807 RET Done
