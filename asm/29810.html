29810: Control code 10: random choice
The next byte is the number of alternatives n, followed by n single items (one or two bytes each). One item is chosen at random and rendered. This is how Louey varies his patter ("[What wuz dat, Boss? I missed it/It's okay, Boss - this line aint tapped...]").
29810 INC IX Point at the number of alternatives
29812 LD A,(IX+0) A=the number of alternatives
29815 LD (29808),A Store it as the counter
29818 DEC A A=n-1
29819 CALL 30014 Pick a random number 0..n-1
29822 INC A A=1..n
29823 LD (29809),A Store the choice
29826 INC IX Point at the first alternative
29828 LD A,(29809) Is this the chosen alternative?
29831 LD HL,29808 HL=the counter of alternatives still to skip
29834 CP (HL) Is this the chosen one?
29835 JR NZ,29844 Jump if not
29837 PUSH IX Keep the message pointer
29839 CALL 29458 Render it
29842 POP IX Restore the message pointer
29844 LD A,(IX+0) Get the first byte of this alternative
29847 BIT 7,A A dictionary word (2 bytes)?
29849 JR NZ,29859 Jump if so
29851 CP 2 Control code 2 (2 bytes)?
29853 JR Z,29859 Two-byte item: skip both bytes
29855 CP 11 Control code 11 (2 bytes)?
29857 JR NZ,29861 Jump if not
29859 INC IX Skip the second byte
29861 INC IX Skip the first byte
29863 LD HL,29808 Count down the alternatives
29866 DEC (HL) One alternative fewer to go
29867 JR NZ,29828 Jump back for the next one
29869 DEC IX Point at the last byte (the caller moves on)
29871 XOR A Set the zero flag: code done
29872 RET Done: the zero flag tells the caller the message continues
