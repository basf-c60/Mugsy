29897: Control code 8 handler (broken backspace)
The handler for message control code 8, which was evidently meant to be a backspace: it steps the text buffer pointer (29926) back one character so that the next character overwrites the last. The jump table at 29248 points here. These bytes are Z80 code; each comment gives the instruction.
It is broken. The first instruction, PUSH HL, is never undone, and the dispatcher (29544) has just put the handler's own address in HL, so the final RET goes back to the start of the handler. The handler then runs a second time and this time returns to 23807, one byte before the start of the text buffer (23808), and executes whatever is there as code. Run in the simulator, the buffer pointer dropped by two and the call never returned. No message in the game uses code 8, so nobody ever sees it (see the bugs page).
29897 DEFB 229 PUSH HL: the stray instruction (nothing ever pops it)
29898 DEFB 42,230,116 LD HL,(29926): HL=the text buffer pointer
29901 DEFB 43 DEC HL: step back one character
29902 DEFB 34,230,116 LD (29926),HL: store the new pointer
29905 DEFB 175 XOR A: set the zero flag (code done)
29906 DEFB 201 RET: return, but to the wrong place because of the PUSH HL
