29928: Expand a dictionary word
Words are stored one byte per letter, of which only the low 5 bits count (1=a ... 26=z, 27-31 punctuation), in the dictionary at 48640. Bit 7 marks the last letter, except on the second letter, or the third if the second also has bit 7 set; this lets short words overlap the starts of longer ones.
Input
D Bits 0-3: dictionary page; bits 4-6: type
E Offset
29928 LD A,D Is the reference zero (no word)?
29929 AND 15 Keep only the page number (low 4 bits of D)...
29931 OR E ...and combine it with the offset in E: zero means no word at all
29932 RET Z Return if so
29933 PUSH HL Save HL...
29934 PUSH BC ...BC...
29935 PUSH DE ...and DE
29936 LD C,D C=type
29937 LD A,D A=the type and page byte
29938 AND 15 D=page (0-15)
29940 LD D,A D=page, so DE=256*page+offset
29941 LD HL,48640 HL=48640+256*page+offset
29944 ADD HL,DE HL=the address of the word's text
29945 LD DE,(29926) DE=where the next character goes in the text buffer
29949 LD A,32 Put a space before the word
29951 CALL 29519 Put the space in the buffer
29954 LD A,(HL) First letter: low 5 bits
29955 INC HL Step on to the second letter
29956 AND 31 Keep the low 5 bits (1-26 = A-Z)
29958 OR 96 Convert to a lower case letter
29960 LD B,A B=letter
29961 LD A,C Is this a capitalised word (type 7)?
29962 AND 240 Look at the type nibble only
29964 CP 112 Is it type 7 (capitalised word)?
29966 JR NZ,29970 Jump if not
29968 RES 5,B Make the letter upper case
29970 LD A,B A=the first letter, upper or lower case
29971 CALL 29519 Put the first letter in the buffer
29974 LD B,1 B counts the letters
29976 LD A,(HL) Next letter
29977 AND 31 Keep the low 5 bits of the next letter
29979 JR Z,30010 A zero letter ends the word
29981 INC B Count it
29982 ADD A,96 Convert to a lower case letter
29984 CALL 29519 Put it in the buffer
29987 BIT 7,(HL) Does bit 7 mark the end of the word?
29989 INC HL Step on to the next byte
29990 JR Z,29976 Carry on if not
29992 LD A,B Bit 7 is ignored on the second letter...
29993 CP 2 Is this the second letter?
29995 JR Z,29976 Yes: its end bit is ignored, so carry on
29997 CP 3 ...and on the third...
29999 JR NZ,30010 Finished if this is the fourth letter or later
30001 DEC HL ...if the second letter also had bit 7 set
30002 DEC HL Step back two bytes to the second letter...
30003 LD A,(HL) ...and pick it up
30004 INC HL Step forward again...
30005 INC HL ...to the byte after the third letter
30006 BIT 7,A Did the second letter have its end bit set?
30008 JR NZ,29976 Carry on if so
30010 POP DE Restore DE...
30011 POP BC ...BC...
30012 POP HL ...and HL
30013 RET Done: the word is in the text buffer
