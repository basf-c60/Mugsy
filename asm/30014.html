30014: Get a random number between 0 and n
Calls 30026 (which returns -n..n) and negates a negative result, so the result is always 0..n. Because of the way 30026 folds large values, the result is not uniform: for n=100, the values 1-27 are twice as likely as the others (raw bytes above 200 are halved, which lands them just above n).
Input
A n
Output
A Random number
