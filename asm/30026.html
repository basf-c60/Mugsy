30026: Get a random number
Steps a pointer through the code of the program itself (30023) and mixes the bytes it finds, ensuring that the same value never comes up twice in a row, halves it until it is no more than 2*A, and subtracts A, giving a number between -A and A.
Input
A Upper limit
Output
A Random number

30028 PUSH BC Save BC
30029 LD C,A C=upper limit

30053 LD A,(30025) Pick up the last random number

30061 XOR (IX+1) Mix in another byte
30064 PUSH HL Save HL
30065 LD HL,30025 Is the new number the same as the last one?

30070 JR Z,30037 Try again if so
30072 LD (30025),A Store the new random number
30075 CP B Halve it until it is no greater than 2*limit
30076 JR C,30085 Within range: done
30078 JR Z,30085 Exactly equal to the limit: done

30089 RET Done: A=a random number from -limit to +limit
