30092: Run a VM script
The game logic is written in a compact interpreted language. IY points at the first instruction; instructions are executed until op 0 (END). See the VM reference page for the full instruction set. The flags returned by each instruction are preserved (PUSH AF/POP AF) so that op 12 (JZ) can test the result of a native routine called by op 14.
Input
IY Script address
30092 LD (30090),IY Set the VM program counter
30096 PUSH AF Save the flags from the previous instruction
30097 CALL 30214 Fetch the opcode
30100 ADD A,A Double it for the jump table at 30123
30101 LD HL,30123 HL=start of the VM jump table
30104 ADD A,L Add the doubled opcode to L...
30105 LD L,A L=the low byte of the entry address
30106 LD A,0 Prepare to add the carry to H...
30108 ADC A,H ...A=H+carry
30109 LD H,A HL=entry in the jump table
30110 LD A,(HL) Pick up the handler address
30111 INC HL Next byte of the entry
30112 LD H,(HL) H=high byte of the handler address
30113 LD L,A L=low byte: HL=handler
30114 POP AF Restore the flags from the previous instruction
30115 CALL 30122 Execute the instruction
30118 JR 30096 Back for the next one
