33888: VM flags
Nine flag bytes that the script tests and sets with IFPEEKEQ, IFPEEKNE and POKE, followed by the game status flag and some workspace used by the speech bubble code. 33937 sets the nine flags and the status flag to 1 at the start of each game; the values below are those in the saved game image.
33888 DEFB 0 Flag 0: the feds flag. 1 normally, 2 when the feds have been tipped off (set at the end of the recruiting step, tested in the next report; see the economics page)
33889 DEFB 0 Flag 1: set to 2 when the ammo comes to 1 grand per hood or less (adequate or not), but never tested
33890 DEFB 0 Flag 2: set to 2 when the game ends early (the mob walks out, Nick the Greek, no money left for ammo, cousin Abe, an empty safe, or the hit man); the end of the game then skips the farewell from the hoods
33891 DEFB 0 Flag 3: Rocco. Set to 2 when Rocco gets uppity; next year's report then halves the takings (if they are 3 grand or more) and changes its wording. Reset to 1 after the report
33892 DEFB 0 Flag 4: the contract. 2 when the hit man is coming, 3 when he has won the shootout (set by 28358); reset to 1 afterwards
33893 DEFB 0 Flag 5: chooses between two openings of the contract warning; never changed from 1, so the second opening is never used
33894 DEFB 0 Flag 6: the ammo flag. 2 when last year's ammo was inadequate and not forgiven (cousin Abe then takes over), 1 otherwise
33895 DEFB 0 Flag 7: 1 in the first year, set to 2 at the end of every year
33896 DEFB 0 Flag 8: the type of the last number entered, set by 27835 (1 negative, 2 zero, 3 exactly 0.01, 4 anything else)
33897 DEFB 0 Game status flag: non-zero ends the main loop at 24614
33898 DEFB 0,0 Default sub-message address
33900 DEFB 0,0 Saved IY
33902 DEFB 121,132 Pointer to this year's bubble layout table (33913 or 33925)
33904 DEFB 0,0 The current bubble layout
33906 DEFB 0 Layout-unchanged flag
33907 DEFB 0,0 Text width
