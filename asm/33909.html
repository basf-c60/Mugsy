33909: Speech bubble layouts
Each entry is 4 bytes: a chance value (compared with a random number from 0 to 100), the address of the picture, and a byte that is always 0. 33909 is the fixed "answer" layout. 33913 and 33925 start the two tables, one of which 24614 picks at random each year; the SAY routine (28549) then takes the first entry in that table whose chance value is above a new random number. See Which background you get on the trivia page for the resulting odds.
