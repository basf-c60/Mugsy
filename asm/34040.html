34040: Run the steps of an animation
IX points at a list of step routine addresses. Once per tick (set by the interrupt routine) the current step is called; while it returns with the zero flag reset it is called again on the next tick, otherwise IX moves on to the next step. The sequence ends when 33993 is set.
Input
IX Step table
34040 LD A,(33993) Has the animation finished?
34043 AND A Test the flag
34044 RET NZ Return if so
34045 EI Enable interrupts
34046 HALT Wait for an interrupt
34047 EI And again, to be sure they are on
34048 LD L,(IX+0) Pick up the address of the current step routine
34051 LD H,(IX+1) H=the high byte of the step routine's address
34054 CALL 34065 Call it
34057 JR NZ,34040 Keep calling it until it returns with the zero flag set
34059 INC IX Then move to the next step
34061 INC IX Next step
34063 JR 34040 Loop back to wait for the interrupt and run the step
