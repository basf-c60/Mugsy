34135: Prepare a pre-shifted masked sprite
Copies the 32x32 sprite whose address is at HL into the buffer at DE, giving each row of 4 graphic bytes a mask byte of 255 and a spare 0 byte, then shifts the whole buffer right A pixels.
Input
This routine has a serious bug: it leaves the buffer address on the stack (PUSH DE ... POP HL; PUSH HL) and so, when A is 0, the RET Z at 34164 "returns" into the sprite buffer and the CPU executes the graphic data. See the bugs page.
