42112: Shootout with the hit man from Detroit
An arcade sequence. Mugsy (controlled with Q/Z up/down, I/P left/right and B/N/M to fire) must shoot the hit man in a restaurant before the hit man shoots him. Installs its own IM2 interrupt routine (48539), sets Mugsy's hit points to (A AND 7)+1 (42301; the hit man always has 4, at 42302), runs the game and restores IM1 on exit.
Input
A Value from the handout: Mugsy gets (A AND 7)+1 hit points (8 if A is 255)
Output
A Result: bit 0 set if Mugsy was killed; bits 2-3 set if bystanders were hit
42112 DI Interrupts off while the IM2 handler is installed
42113 PUSH AF Save the strength value passed in A (it is needed again below)
42114 LD HL,48539 HL=address of the shootout's interrupt routine
42117 LD (53457),HL Patch it into the JP at 53457 that the IM2 vector table (53504) leads to
42120 LD A,209 A=209: the high byte of the vector table address, which is filled with 208
42122 LD I,A Set the interrupt vector register: IM 2 interrupts now vector through 53504
42124 IM 2 Select interrupt mode 2
42126 LD A,0 A=0: black border, speaker off
42128 OUT (254),A Set the border colour and speaker
42130 POP AF Get the strength value back
42131 AND 7 Keep the low 3 bits (0-7)
42133 INC A Add 1 to make 1-8
42134 LD (42301),A Store it as Mugsy's hit points (the hit man's bullets take one off each time they hit him)
42137 CALL 42639 Draw the restaurant and put the figures in place
42140 CALL 42977 Main loop: let any figure whose timer says it is ready decide what to do next
42143 CALL 44766 Deal with Mugsy's and the hit man's bullets landing
42146 CALL 44884 Deal with anyone who has been hit
42149 LD A,(42335) A=the "shootout over" flag (set when Mugsy or the hit man has fallen over)
42152 AND A Test it
42153 JR Z,42140 Keep going until it is set
42155 LD BC,65535 BC=65535: a pause of about a second and a half so the player can see the result
42158 DEC BC Count BC down
42159 LD A,B A=B
42160 OR C Combine with C to test for zero
42161 JR NZ,42158 Loop until BC is zero
42163 LD A,63 A=63: the high byte of the ROM's interrupt table address
42165 LD I,A Put the interrupt vector register back as the ROM expects it
42167 IM 1 Back to interrupt mode 1
42169 LD A,(42334) A=the result bits (bit 0 Mugsy killed, bit 1 hit man killed, bit 2 bystander 1 hit, bit 3 bystander 2 hit)
42172 DI Leave with interrupts disabled (the caller restores the ROM's FLAGS)
42173 RET Return to the VM's native-call routine
