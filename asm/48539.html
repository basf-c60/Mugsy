48539: Interrupt routine for the shootout: the sprite scheduler
Runs fifty times a second. For each figure whose timer is 0 it counts down the figure's countdown; when that reaches zero it points SP at the figure's record and uses POP to load HL, DE, BC and IY from it, then jumps to IY: a sprite drawing routine (45965, 46031, 46119 or 46196) that draws the figure with the registers already set up. The drawing routines pass control on through 48601 and finish at 48617, which restores the real stack and sets the timer to 1. The routine ends by reading the keyboard.
