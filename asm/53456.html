53456: Interrupt jump
The IM2 vector table at 53504 is filled with 208, so every interrupt jumps here (53456=208*257). The address is set to 34069 or 48539 when interrupts are enabled. Note that these three bytes sit in the middle of leftover assembler source text (see the trivia page).
